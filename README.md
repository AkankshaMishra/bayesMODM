# bayesMODM: Bayesian Preference Learning for Multi-Objective Decision-Making

This repository contains the implementation of a Bayesian framework for learning latent scalarization weights from pairwise preference information and supporting adaptive decision-making in multi-objective optimization.

The framework assumes that a decision-maker expresses preferences through pairwise comparisons between candidate solutions. These comparisons are used to infer latent scalarization weights that characterize the relative importance of multiple objectives. The repository includes both Bayesian continual learning (BCL) and batch Bayesian inference approaches for preference learning.

# Methodology

The proposed framework consists of the following steps:

1. Generate Pareto-optimal solutions for a multi-objective optimization problem.
2. Obtain pairwise preference information between candidate solutions.
3. Learn latent scalarization weights using a Bayesian preference model.
4. Update preference beliefs sequentially using Bayesian Continual Learning (BCL).
5. Identify solutions that align with the learned preferences.

The Bayesian preference model is implemented in Stan and interfaced through R.

# Folder: Tanaka

This folder contains experiments based on the classical Tanaka multi-objective optimization problem.

## Contents

### Bayesian Continual Learning

R scripts implementing sequential Bayesian updating of preference beliefs as pairwise comparisons are observed over multiple iterations.

### Batch Bayesian Inference

R scripts implementing Bayesian inference using all available preference observations simultaneously.

### Stan Model

Stan model defining the Bayesian preference learning framework for the Tanaka problem.

### Visualization Scripts

Scripts for generating figures including:

- Evolution of posterior weight estimates
- Learned preference distributions
- Solution trajectories
- Objective-space visualizations
- Pareto-front plots

### Ground Truth Pareto Solutions

The `.rda` file contains feasible Pareto-optimal solutions generated using the NSGA-II algorithm and serves as a reference set for evaluation.

# Folder: PortfolioOptimization

This folder contains experiments on preference-aware portfolio optimization.

## Contents

### Bayesian Continual Learning with Hierarchical Preference Generation

Implementation of Bayesian continual learning where pairwise preferences are generated from a hierarchical preference model.

### Bayesian Continual Learning with LLM-Generated Preferences

Implementation of Bayesian continual learning using pairwise preferences generated by a Large Language Model (LLM) through carefully designed prompts that simulate investor preferences.

### Batch Bayesian Inference

Implementation of Bayesian preference learning using all preference observations simultaneously.

### Stan Model

Stan model defining the Bayesian preference learning framework for the portfolio optimization problem.

### Visualization Scripts

Scripts for generating:

- Posterior weight trajectories
- Preference evolution across iterations
- Portfolio solutions in objective space
- Pareto-front visualizations
- Comparative analysis of batch and continual learning approaches

# Running the Experiments

### Tanaka Problem

1. Load the Pareto solution set stored in the `.rda` file.
2. Compile the corresponding Stan model.
3. Run either:
   - Batch Bayesian inference, or
   - Bayesian Continual Learning.
4. Use the plotting scripts to reproduce figures.

### Portfolio Optimization

1. Prepare portfolio objective values.
2. Generate preference observations:
   - Hierarchical preference model, or
   - LLM-generated preferences.
3. Compile the portfolio Stan model.
4. Run batch or continual Bayesian inference.
5. Generate visualizations using the provided plotting scripts.
